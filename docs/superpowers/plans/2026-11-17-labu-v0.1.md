# labu v0.1 (record / replay OpenAI-compatible) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `labu record -- <cmd>` merekam semua call OpenAI-compatible dari `<cmd>` ke cassette, dan `labu replay -- <cmd>` memutarnya ulang byte-per-byte tanpa jaringan dan tanpa kredensial.

**Architecture:** `labu` menyalakan proxy HTTP lokal di port acak, menjalankan `<cmd>` dengan `OPENAI_BASE_URL` diarahkan ke proxy, lalu mencetak ringkasan saat `<cmd>` selesai. Logika murni (kunci matching, cassette, scanner, mesin replay) ada di `labu-core` yang tidak punya dependensi jaringan. Server replay (`labu-replay`) tidak punya HTTP client; hanya `labu-record` yang punya.

**Tech Stack:** Rust 2021, `tokio`, `axum` 0.8, `reqwest` 0.12 (hanya di `labu-record`), `clap` 4, `serde`/`serde_json`, `sha2`, `base64`, `regex`, `thiserror`. Tes e2e: Python + SDK `openai`.

**Spec:** `docs/PLAN.md` (bagian 2, 3, 5) dan `docs/adr/0001-v0.1-decisions.md`. Urutan kerja: `HANDOFF.md` langkah 5.

## Global Constraints

- Lisensi `Apache-2.0`. Edition 2021. Semua crate baru masuk `members` di `Cargo.toml` root.
- Empat invariant (`HANDOFF.md`): **raw-bytes cassette**, **client-less replay**, **header allowlist**, **canary secret**. Tes tiap invariant ditulis sebelum kodenya.
- Gate tiap task: `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`.
- Pemilik proyek masih belajar Rust: hindari macro buatan sendiri, lifetime eksplisit, dan generic yang tidak perlu. Komentar singkat berbahasa Indonesia di bagian async dan trait.
- `labu --help` hanya menampilkan `record` dan `replay`.
- Alamat Bifrost dan API key tidak pernah ditulis ke file mana pun di repo.
- Satu branch fitur aktif. Ide baru masuk `LATER.md`, bukan ke plan ini.
- Sebelum Task 1: buat commit dasar dari scaffold yang ada (belum ada commit selain `Initial commit`), lalu branch `feat/v0.1`.

## Keputusan yang menyimpang dari `docs/PLAN.md`

| Hal | Keputusan v0.1 | Alasan |
|---|---|---|
| Redaction PII di body respons | Respons **tidak pernah diubah**. Scanner memeriksa teks respons; kalau ada temuan, rekaman **gagal** (default) atau disimpan apa adanya dengan `--on-finding allow` | Mengubah byte respons melanggar raw-bytes cassette, dan PII bisa terpecah antar-delta SSE |
| Redaction PII di body request | Salinan request di cassette di-mask (`[NIK]`, `[PHONE]`, ...). Kunci matching dihitung dari request asli | Salinan request hanya dipakai untuk diff saat miss, jadi aman diubah |
| Mode strict saat `CI=true` | Tidak ada mode lain: replay tidak pernah meneruskan ke jaringan | Sudah dijamin struktur crate |
| `labu lint`, timing replay, tes SDK TypeScript, `labu migrate`, canary mingguan | Tidak masuk v0.1; dicatat di `LATER.md` (Task 9) | Cakupan v0.1 sengaja kecil (bagian 3 dan 5.1) |

## Review Focus

1. **Body request besar** (konteks RAG > 2 MB): harus diterima; limit bawaan axum mematikannya. Tes di Task 5 dan 6.
2. **Respons terkompresi**: klien mengirim `accept-encoding: gzip`; proxy tidak boleh meneruskannya, supaya byte yang direkam bisa dibaca saat replay. Tes di Task 6.
3. **Request paralel** (embedding batch): baris cassette tidak boleh saling menimpa. Tes di Task 6.
4. **Stream putus di tengah** (upstream mati, agent di-kill): entri setengah jadi tidak boleh tertulis. Tes di Task 6.
5. **Respons error upstream** (429/500): diteruskan ke klien, tidak direkam, dihitung. Tes di Task 6.

```rust
pub struct ReplayEngine { /* privat; kursor urutan di dalam Mutex */ }
pub enum Outcome { Hit { status: u16, headers: BTreeMap<String, String>, body: Vec<u8> }, Miss(Miss) }
pub struct Miss { pub method: String, pub path: String, pub key: String, pub nearest: Option<Nearest> }
pub struct Nearest { pub entry_index: usize, pub differing: Vec<String> }   // JSON pointer, terurut
#[derive(Clone, Copy, Debug, PartialEq, Default)]
pub struct ReplayStats { pub hits: u64, pub misses: u64 }
impl ReplayEngine {
    pub fn new(cassette: Cassette, provider: Box<dyn Provider + Send + Sync>) -> ReplayEngine;
    pub fn base_path(&self) -> &str;
    pub fn respond(&self, method: &str, path: &str, body: &[u8]) -> Outcome;
    pub fn stats(&self) -> ReplayStats;
}
impl Miss { pub fn to_error_json(&self) -> serde_json::Value; }
```
Aturan urutan: N entri dengan kunci sama disajikan sesuai urutan rekaman; setelah habis, entri terakhir diulang. `nearest`: di antara entri dengan `method` + `path` sama, pilih yang jumlah pointer berbedanya paling sedikit (seri → indeks terkecil); request masuk di-mask dulu dengan `mask_json_strings` sebelum dibandingkan. Pointer menunjuk daun yang berbeda; array beda panjang → pointer array itu.

**Interfaces:**

- Produces (antarmuka pengguna):

```
labu record --upstream <URL> [--cassette <PATH>] [--on-finding <fail|allow>] -- <command>...
labu replay [--cassette <PATH>] -- <command>...
```
- `--upstream`: persis nilai `OPENAI_BASE_URL` agent hari ini (mis. `http://host:8080/v1`); bisa lewat env `LABU_UPSTREAM`. Origin → `upstream_origin`; path → `Meta.base_path`.
- `--cassette`: default `labu.cassette.jsonl`. `--on-finding`: default `fail`.
- Proxy bind `127.0.0.1:0`. Env proses anak: `OPENAI_BASE_URL=http://127.0.0.1:<port><base_path>`, `LABU_MODE=record|replay`. Saat replay, `OPENAI_API_KEY=labu-replay` di-set hanya jika belum ada.
- Ringkasan ke stderr, persis:
  - `labu replay: hits: <n>, misses: <n>, live calls: 0`
  - `labu record: recorded: <n>, live calls: <n>, upstream errors: <n>`
  - saat diblokir, satu baris per temuan: `labu record: blocked <path>: <label,label>` lalu `labu record: cassette not written (use --on-finding allow to override)`

| Exit code | Arti |
|---|---|
| kode proses anak | kalau proses anak keluar ≠ 0 |
| 0 | sukses |
| 2 | kesalahan `labu` sebelum proses anak jalan (cassette tidak ada / rusak, `--upstream` kosong) |
| 3 | replay: proses anak sukses tapi `misses > 0` |
| 4 | record: cassette diblokir temuan |
