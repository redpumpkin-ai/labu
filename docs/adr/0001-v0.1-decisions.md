# ADR 0001: Keputusan v0.1

*Status: diterima · 16 November 2026 · direvisi 17 November 2026 (provider pertama: Bifrost)*

Jawaban atas pertanyaan terbuka di `HANDOFF.md` langkah 1.

| Pertanyaan | Keputusan |
|---|---|
| Provider yang dipanggil agent | **Bifrost** (gateway LLM). Agent memanggil Bifrost, dan Bifrost yang meneruskan ke model (termasuk yang di AWS Bedrock). Agent memanggil Bifrost lewat **API OpenAI-compatible**, jadi adapter pertama `labu` = OpenAI-compatible |
| Level Rust | Masih belajar sambil jalan. Kode ditulis sederhana, dengan komentar singkat di bagian async dan trait yang penting |
| Org GitHub | `redpumpkin-ai` milik RedPumpkin.AI (dikonfirmasi lisan oleh pemilik proyek; belum dicek di GitHub) |
| Lisensi | **Apache-2.0** saja (bukan dual MIT). MIT bisa ditambah belakangan |
| Agent pengguna pertama | Agent RAG internal, Python. **Belum punya test suite** |

## Setup Bifrost (17 Nov)

| Hal | Jawaban |
|---|---|
| Endpoint | `/v1/chat/completions` dan embedding, keduanya lewat Bifrost |
| Library klien | SDK `openai` Python. `labu` tidak boleh bergantung pada library tertentu |
| Streaming | Agent pakai `stream=True`. `labu` harus mendukung streaming (SSE) **dan** non-streaming |
| Lokasi Bifrost | Server remote. Alamatnya **tidak ditulis di repo**: diberikan lewat konfigurasi (`--upstream` / env) saat record |

## Riwayat keputusan provider

- 16 Nov: dijawab "AWS Bedrock" dengan boto3. Spike SigV4 dimulai.
- 17 Nov: pemilik proyek mengoreksi: agent memanggil lewat Bifrost, bukan boto3 langsung. Provider pertama diganti ke Bifrost. Bedrock langsung (SigV4) turun jadi adapter kedua, paling cepat v0.2.

## Hasil spike Bedrock (dihentikan sebelum call asli)

Kode di `spikes/bedrock/`. Yang terbukti dengan upstream palsu (`test/local_test.sh`):

- Record lalu replay byte-equal untuk frame event-stream biner; boto3 bisa mem-parse hasil replay.
- Proxy replay jalan tanpa kredensial AWS dan tanpa jaringan; miss dijawab 501, tidak diteruskan.
- Cassette hanya menyimpan header `content-type`; kredensial, tanda tangan, dan cookie tidak sampai ke disk.

Yang **belum** terbukti: tanda tangan SigV4 diterima AWS asli, dan frame event-stream asli dari Bedrock. `test/real_test.sh` sudah ditulis tapi belum pernah dijalankan.

Temuan yang berguna untuk adapter Bedrock nanti:

- Profil `aws login` butuh fitur cargo `credentials-login` di `aws-config`.
- Saat replay, klien boto3 tetap butuh kredensial dummy dan `AWS_DEFAULT_REGION`, karena ia menandatangani sebelum mengirim.

## Konsekuensi

- `HANDOFF.md` langkah 3 (spike Bedrock) dilewati sesuai aturannya sendiri: provider yang dipilih bukan Bedrock.
- Inti yang terbukti di spike (byte mentah, hash kunci, replay tanpa client, allowlist header) dipakai untuk adapter Bifrost. Bagian tanda tangan tidak diperlukan.
- Karena belum ada test suite, kriteria langkah 5 mengharuskan kita menulis dulu sekumpulan kecil test untuk agent RAG itu.
- Pada agent RAG, hasil retrieval masuk ke prompt. Kalau retrieval tidak stabil antar-run, hash request berubah dan replay miss. Test harus memakai korpus dan retrieval yang dibekukan.

## Belum diputuskan

- Port dan skema (http/https) Bifrost.
- Cek merek dagang dan amankan nama di crates.io (tugas manusia, lihat plan bagian 5.6).
